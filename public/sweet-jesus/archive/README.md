# Sweet Jesus — selected image archive

These are earlier **selected** launderette and opening references, saved so that no voted image is lost. They are historical reference images, **not** the final continuity-locked opening boards: some show a radio or boombox, missing towels, solo coverage before Peanut leaves, or a portrait/ultrawide composition. Do not use them as continuity masters without checking the screenplay and the current style sheets.

The archived WebP files were encoded **losslessly** from the original selected PNGs and verified to decode to identical pixels. `manifest.json` records source and saved checksums, dimensions and saved locations. The selected interior, exterior and table images already have pixel-identical lossless copies in `../launderette/`; the selected washer two-shot has its unchanged original PNG in `../opening/brothers-washer-voted.png`.

In particular, `generated/cassette-with-mic-voted-original.webp` is the original **opaque, checkerboard-backed** vote, kept only for the record. The corrected transparent recorder **with its complete microphone and cable** is `../launderette/cassette-with-mic.png`.

The 14 unmodified cast portrait PNGs are in `../characters/`; the current opening selections are in `../opening/`.
